# Gameplay Test Plan — v1.1 Aggressive Duels

Use the same team, squad, tactical setup, and comparable opponents when comparing v1.0 with v1.1. Ideally start from the same saved-game state and avoid drawing conclusions from a single match.

## What to record

- Tackles attempted and completed, interceptions, and loose-ball recoveries.
- Fouls, yellow/red cards, and injuries.
- Shoulder-to-shoulder challenges, sliding tackles, rebounds, and player recovery after contact.
- Any sliding, unnatural movement, exaggerated collisions, or unexpected goalkeeper behavior.
- Shots, goals, xG, and passing outcomes to check for unintended side effects.

## Suggested sequence

1. Run at least three initial matches with each version to catch obvious issues.
2. If the build is stable, expand the sample across different tactics, teams, and home/away fixtures.
3. Compare aggregated statistics and review full-match footage before claiming any balance improvement.
4. If you see serious anomalies, restore your backup or return to v1.0.

**Note:** Three matches are a smoke test, not enough to establish realism or balance. v1.1 has not yet completed broad gameplay validation.
